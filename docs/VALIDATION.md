## 실계정 검증과 구분

스트리머 API는 공식 웹 클라이언트의 공개 경로·필드를 확인하고 모의 응답으로 구현을 검증했습니다. 실제 채널 소유자 로그인으로 전체 방송·성별·후원·선물·제한 기록이 성공하는지는 검증하지 않았습니다. 일반 시청자의 본인 제한 조회 권한도 보장하지 않습니다. 실계정에서 API가 거절되거나 스키마가 다르면 부분 수집과 실패 이유를 표시합니다.

확장 테스트의 API는 합성 응답입니다. 실제 브라우저 쿠키·인증 성공을 보장하는 테스트가 아닙니다. Edge 수동 설치와 일반 사용자의 다양한 환경을 직접 검증하지 않았습니다.

자동 EXE UI 검증은 개발 실행과 unpacked 실행 파일을 대상으로 합니다. portable 자체의 자동 디버거 연결과는 별개입니다. 릴리스는 코드 서명 없는 Windows x64 portable입니다.
