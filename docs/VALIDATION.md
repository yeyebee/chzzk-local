로그인 만료를 모의해 0페이지에서 중단될 때 오류 원인·로그인/계정 확인 버튼이 상단에 표시되는지, 성공 진행 막대가 숨겨지는지 확인했습니다. 재로그인 후 안내 전환, 기존 기록과 수집 옵션 보존도 확장 통합 테스트로 검증했습니다.

채팅 이어서 수집 시 목록·최근 채팅·차단 요청 생략, 미완료 다시보기가 최근 목록에서 밀려나도 저장 커서부터 재개, 완료 기록 건너뛰기, 전체 선택 채널에 공통 페이지 한도 적용, 다시보기 목록 오류 시 기존 미완료 기록 재개를 검증했습니다. 수집 옵션의 계정별 저장·재시작 복원과 1회 재조회 초기화도 EXE 저장소 및 실제 MV3 통합에서 확인했습니다. 통합 테스트의 비동기 상태 확인은 완료 조건을 명시적으로 반복 확인합니다.

## 실계정 검증과 구분

구체적인 발견 사항과 수정·남은 한계는 [전체 검토 내역](REVIEW-2026-11-13.md)에 기록했습니다.

스트리머 API는 공식 웹 클라이언트의 공개 경로·필드를 확인하고 모의 응답으로 구현을 검증했습니다. 실제 채널 소유자 로그인으로 전체 방송·성별·후원·선물·제한 기록이 성공하는지는 검증하지 않았습니다. 일반 시청자의 본인 제한 조회 권한도 보장하지 않습니다. 실계정에서 API가 거절되거나 스키마가 다르면 부분 수집과 실패 이유를 표시합니다.

확장 테스트의 API는 합성 응답입니다. 실제 브라우저 쿠키·인증 성공을 보장하는 테스트가 아닙니다. Edge 수동 설치와 일반 사용자의 다양한 환경을 직접 검증하지 않았습니다.

자동 EXE UI 검증은 개발 실행과 unpacked 실행 파일을 대상으로 합니다. portable 자체의 자동 디버거 연결과는 별개입니다. 릴리스는 코드 서명 없는 Windows x64 portable입니다.
