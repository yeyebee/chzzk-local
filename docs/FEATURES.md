# 기능과 계산 범위

## 실행 형태

| 기능 | EXE | Chrome / Edge 확장 |
|---|---|---|
| API·분석·화면 | 공통 코드 | 공통 코드 |
| 로그인 | 내장 창 별도 세션 | 기존 브라우저 |
| 보관 | 로컬 JSON, 최소/예시/전체 | IndexedDB, 최소/예시/전체 |
| 재생 관찰 | 내장 치지직 창 1개 | 같은 브라우저의 치지직 탭들 |
| 계속 수집 | 앱을 열어 두어야 함 | 대시보드 탭을 열어 두어야 함 |
| 내보내기 | OS 파일 대화상자 | 브라우저 다운로드 |
| 로그아웃 | 앱 세션 삭제 | 연결 해제만 |
| 동기화·가져오기 | 미지원 | 미지원 |

수집 API의 원리는 같지만 인증·브라우저 정책에 따라 성공 여부가 달라질 수 있습니다.

## 개인 기록과 재생시간

팔로우·포인트·현재/종료 구독·선택 연도부터의 치즈 사용 내역. 최근 내 메시지와 공개 다시보기에서 로그인 ID와 같은 정상 채팅을 저장합니다. 채널/시각/본문이 같은 메시지는 합치고 다시보기 링크를 우선 남깁니다.

기본 5개 채널 × 최근 3개 다시보기, 총 300페이지. 직접 채널 ID/주소를 지정할 수 있으며 최대 채널 30개, 채널당 다시보기 50개, 실행당 10,000페이지입니다. API 반복·상한은 부분 결과로 알립니다. 개인 제한 조회도 같은 선택 채널만 대상으로 하며 일반 사용자에게 거절될 수 있습니다. 전체 채널 차단 목록이 아닙니다.

재생시간은 5초마다 플레이어 위치 변화를 관찰합니다. 일시정지·버퍼링·절전·큰 탐색을 제외하고 겹치는 벽시계 구간을 합칩니다. 다중 탭은 채널별 합이 전체 중복 제거 시간보다 클 수 있습니다. 집중 시청과 광고를 완벽히 판별할 수 없으며 수집 중은 측정을 쉽니다. 과거 시청시간을 복원하지 않습니다.

## 방송 분석

방송 이력은 30일 단위, 최대 3년. 평균·최고 동시 시청자/순 방문자는 응답에 있을 때만 표시합니다. 성별·연령은 최근 10개 방송이 기본(최대 100개), 방송별 공식 집계만 표시하며 서로 다른 비율을 단순 평균하지 않습니다.

- 방송일: 한국 시각 오전 5시 경계, 종료 후 30분 이내 재개는 이전 방송일에 묶음.
- 15분 미만 방송일은 일별/보통 하루 집계에서 제외. 전체 목록·시간대 히트맵에는 남음.
- 보통 길이: 포함된 방송일 길이의 **중간값**.
- 후원: 시작 10분 전부터 종료 10분 후까지 방송일 연결, 나머지는 방송 밖 후원. 환불액 차감·취소/실패 제외.
- 분류: 0 → 후원 없음; 양수 방송일 평균의 4배 이상 → 큰 이벤트일; 중간값 2배 이상 → 많은 날; 절반 미만 → 적은 날; 나머지 → 보통. 특별한 사건의 사실 판정이 아닌 계산 규칙.
- 구독권은 장수이며 치즈로 환산하지 않음. 자료별 조회 기간이 다를 수 있으므로 수집 결과 확인 필요.

## 시청자 분석과 제한 정보

구독자·팔로워·다시보기·선택한 후원/선물을 합칩니다. 상세 조회 대상은 구독·채팅·후원 순위에서 번갈아 고른 최대 200명(기본 50명). 목록은 페이지당 50명 × 기본 20페이지(최대 200페이지). 대상 밖 제한 횟수는 조회 안 됨입니다.

채팅 수는 스튜디오 누적값 우선, 없으면 선택 기간의 다시보기 메시지입니다. 유형은 상세 과거 메시지가 있으면 그 범위, 없으면 다시보기 집계입니다. 둘을 더해 중복시키지 않습니다. **누적값·현재 구독·상세 과거 메시지는 선택 기간으로 자를 수 없는 값**입니다.

출석은 다시보기별 메시지 유무, 10분 활동 칸은 메시지가 한 번이라도 있는 칸입니다. 실제 출석/시청시간이 아니며 무채팅 시청자를 관측할 수 없습니다. 처음/끝 관련 상은 끝까지 조회한 다시보기만 씁니다.

46개 시상 기준은 수치 26개와 정규식 20개입니다. `RULES`, `AWARDS`와 앱 데이터 사용 안내에 전부 공개합니다. 화면 순번은 동점 공동 순위가 아니며 동점은 닉네임순입니다. AI 성격·의도·감정 판정이 아니고 오분류·중복 분류가 가능합니다. 최근 활동 필터는 마지막 채팅·후원·선물로 **사람을 선택**하며 그 사람의 누적값을 기간별로 다시 계산하지 않습니다.

`restrict`/`temporaryRestrict`는 현재 상태, `restrictCount`/`temporaryRestrictCount`는 서버 누적 횟수입니다. 조회 기간 내 횟수가 아닙니다. 과거 횟수가 있어도 현재 제한 중인 것은 아닙니다. 상세 사건·사유·영구 여부는 표시하지 않으며 제한을 실행/해제하지 않습니다.

## 부분 수집과 미지원

다시보기 최대 500개/20,000페이지, 상세 메시지 최대 10,000페이지와 서비스 보관기간·권한에 제한됩니다. 다음 실행에서 커서를 이어가며 재조회는 해당 집계를 교체합니다. 스냅샷 실패는 이전 자료와 성공 당시 기간을 유지하고 실패로 표시합니다.

삭제·비공개 기록 복구, 과거 정확한 전체 시청시간, 전체 채널 차단 탐색, 개인 성별 추정, AI 성격 유형, 영상/미션 성공·실패 판정, 클라우드 리포트·동기화는 미지원입니다. 값이 없다는 것은 행동이 없었다는 뜻이 아닙니다.
